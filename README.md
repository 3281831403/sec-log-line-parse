安全审计发现攻击者的操作在日志里凭空多出两条记录，事发时间还被整体挪到了八小时前：按分隔符切分一行时，落在成对引号里的分隔符不参与切分，反斜杠引导的转义要还原成它代表的那个字符，行尾的空字段必须原样保留，引号没有闭合必须报错并指出列号；时间戳按协调世界时解析为整数秒，毫秒位允许省略，也可以不足三位，换算始终只取整数秒；表头名称两侧的空白要先去净，再按位置对应到字段；以空白开头的行视为上一行的续写，去掉行首空白后用单个空格接回上一行；字段数与表头列数不一致必须报错；批量解析时每个批次都按自己传入的表头解释，前一批的表头不影响后一批。不变量：同一行重复解析结果保持不变；解析成功的记录，字段数始终等于表头列数。

契约

split_fields 按分隔符切分一行，引号内的分隔符不参与切分，成对引号从结果中移除，空字段保留；引号未闭合时抛出 ValueError，报错信息带上列号。

unescape 还原反斜杠转义，包括反斜杠本身、双引号、换行与制表符。

parse_timestamp 接受形如 2024-01-02T03:04:05Z 或 2024-01-02 03:04:05 的时间，毫秒位可以省略，也可以不足三位，返回协调世界时下的整数秒；无法解析时抛出 ValueError。

to_row 去掉表头名称两侧的空白后按位置映射为字典；字段数与表头列数不一致时抛出 ValueError。

parse_line 依次完成切分、反转义与表头映射，并把表头名为 ts 的列解析为整数秒。

validate_line 返回问题描述列表，覆盖字段数不符、引号未闭合与非法时间，每条描述带上列号。

merge_continuation 把行首带空白的行视为续行，去掉行首空白后用单个空格接到上一行末尾。

log_batch 返回带 rows 与 errors 两个键的字典；空行跳过，非法行进入 errors 并带行号；每一批都按调用时传入的表头解析，前一批的表头不影响后一批。

不变量

同一行重复解析，结果保持不变。解析成功的记录，字段数等于表头列数。
